# 幸运点点名 · 星愿花庭 ✨

一款带有插画与动画效果的 Windows 桌面点名器，让课堂点名多一点仪式感。

## ✨ 功能

- **单抽 / 五连 / 十连**：分别抽取 1、5、10 位同学，同一轮内姓名不重复；不同轮之间可以重复。
- **公平抽取**：等概率无放回抽样，每轮随机出现一张金色卡片；金色卡片不改变姓名的抽取概率。
- **班级管理**：新建班级、编辑名单，支持 CSV 和 XLSX 导入。
- **动画效果**：花庭背景、小猫动画、花瓣星光与逐卡展示，可调整抽取时长并跳过动画。
- **历史记录**：自动保存点名结果，支持查看和导出历史。
- **全屏展示**：按 F11 切换全屏，按 Esc 退出全屏。

## 🚀 使用方法

1. 在 Windows 10/11 的 64 位电脑上下载并打开 `幸运点点名-星愿新版.exe`。
2. 新建班级，手动填写姓名，或导入 Excel / CSV 名单。
3. 选择单抽、五连或十连，等待结果展示。
4. 根据需要调整动画时长、开关音效或查看点名历史。

只需复制 EXE 即可运行，无需同时携带图片、音效、源码或名单文件。首次启动需要将内置资源解压到系统临时目录，可能稍慢。

本程序面向 Windows x64；macOS、Linux 和 32 位 Windows 无法直接运行此 EXE。目标电脑需要允许程序访问用户数据目录与临时目录。

## 📋 名单格式

- XLSX：读取第一张工作表，优先识别“姓名”“名字”或 `name` 列，否则读取第一列。
- CSV：支持 UTF-8 和 GB18030 编码。
- 相同姓名会自动合并；如有重名同学，请在姓名后添加学号或其他区分标记。
- 人数不足时无法进行对应人数的抽取，例如十连至少需要 10 个不同姓名。

## 💾 数据保存与迁移

名单、设置和点名历史保存在：

```text
%LOCALAPPDATA%\LuckyRoll\data.json
```

复制 EXE 不会自动迁移这些数据。如需保留原有名单和历史：

1. 关闭两台电脑上的程序。
2. 在原电脑按 Win + R，输入 `%LOCALAPPDATA%\LuckyRoll`，备份 `data.json`。
3. 在新电脑运行一次程序后关闭，将备份文件复制到新电脑的相同位置。
4. 如目标位置已有数据，请先备份，再替换。

程序不自动进行云同步。请妥善保管含有同学姓名的名单与历史文件。
